# zurich-thaimassage-site

### 1. pull the project
```bash
git pull
```

### 2. update backend and start it
```bash
npm install
npm start
```
### 3. start frontend
```bash
 python3 -m http.server 3000
```

----------
frontend runns on http://localhost:3000 (connected with the backend)<br>
backend runns on http://localhost:4000
